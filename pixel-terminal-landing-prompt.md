# PROMPT → Claude Code: pixel-terminal лендинг (клон структуры Status Code 1) под stock mining protocol

> **Как пользоваться:** скопируй весь файл в Claude Code как единый бриф. Плейсхолдеры вида `{{PROJECT_NAME}}` замени на свои значения до запуска. Раздел 4 содержит две палитры: **A — оригинал 1:1** и **B — адаптация под проект**. Оставь ту, которую собираешь, вторую удали, чтобы модель не металась.

---

## 1. РОЛЬ И ЗАДАЧА

Ты — фронтенд-разработчик и pixel-art дизайнер. Собери одностраничный лендинг, **структурно и композиционно повторяющий референс 1 к 1** (сайт хакатона в pixel/terminal-эстетике), но с контентом проекта:

> **{{PROJECT_NAME}} — balance-powered stock mining protocol on Robinhood Chain. Trading fees become tokenized TSLA rewards.**

Ключевое правило: **референс — это закон по вёрстке, ритму и эффектам.** Не «вдохновляйся», а воспроизводи: тот же порядок секций, те же типы блоков, те же размеры относительно вьюпорта, те же микровзаимодействия. Свобода — только в палитре, копирайте и иллюстрациях.

**Запрещено:** менять порядок секций, заменять pixel-эстетику на «современный SaaS», использовать градиентные glassmorphism-карточки, закруглять углы у блоков (кроме одной CTA-кнопки), добавлять секции, которых нет в референсе.

## 2. СТЕК

- **Next.js 14+ (App Router) + TypeScript**
- **Tailwind CSS** (кастомные токены в `tailwind.config.ts`, никакого произвольного inline-стайлинга кроме динамики)
- **Framer Motion** — скролл-ревилы, каруселей transitions
- **Canvas API** — звёздное поле (не 300 `<div>`, а один `<canvas>`)
- Шрифты через `next/font/google`
- Без UI-китов (никаких shadcn/MUI) — всё руками, иначе поедет пиксельность
- Деплой: статический экспорт, Vercel-ready

### Вариант B — адаптация под {{PROJECT_NAME}}

Идея: «биржевой терминал в глубоком космосе». Зелёный = ап-свеча/эмиссия наград, красный = даун-свеча/тикер, золото = накопленный TSLA-фрагмент. Красный больше **не** декоративный акцент, а осмысленный сигнал.

```css
--bg-deep:      #04070F;   /* near-black с синим подтоном */
--bg-mid:       #0A1220;
--bg-soft:      #131E33;
--signal:       #00E05A;   /* главный акцент: цифры, префикс терминала, CTA */
--signal-dim:   #0E8F45;
--steel:        #8FA3BE;   /* body-текст */
--ticker-red:   #FF3B47;   /* down-состояния, акцентный символ в лого */
--gold:         #FFB020;   /* награды, знак $ */
--violet:       #6C63FF;   /* второстепенный акцент, ссылки */
--white:        #EAF2FF;
```

Соответствие ролей 1:1 с оригиналом (чтобы не сломать композицию):
`violet → violet`, `magenta → signal`, `red → ticker-red`, `gold → gold`, `orange → gold-dim`, `term-green → signal`, `lavender → steel`.

### Типографика

| Роль | Шрифт | Применение |
|---|---|---|
| Display | **Press Start 2P** | H1, названия треков, суммы, футер-вотермарк, лого. Крупно и редко. |
| Body / UI | **Silkscreen** (или **VT323** для более «терминального» вида) | Параграфы, навигация, FAQ, подписи |
| Mono / данные | **Departure Mono** или fallback `ui-monospace` | Terminal-заголовки, цифры каунтдауна, тикеры |

Правила:
- `line-height: 1.7` для body — пиксельные шрифты слипаются при меньшем.
- `letter-spacing: 0.06em` для навигации и капса, `0.03em` для заголовков.
- **Никакого антиалиасинга на спрайтах:** `image-rendering: pixelated;` для всех `<img>` из `/public/pixel/`.
- Тип-шкала (десктоп): 72 / 54 / 34 / 26 / 20 / 16 / 14 / 12 / 10 px.

### Сетка и ритм

- Контейнер `max-width: 1200px`, боковые паддинги 40 px (desktop) / 20 px (mobile).
- Вертикальный ритм секций: `padding-block: 120px`, у Tracks — `min-height: 100vh`.
- **Базовый юнит — 4 px.** Все отступы кратны 4, иначе пиксель-сетка визуально расползётся.
- `border-radius: 0` глобально. Исключения: CTA-пилюля (24 px) и лого партнёра (6 px).

## 5. ГЛОБАЛЬНЫЕ СЛОИ (порядок z-index снизу вверх)

1. **Градиентный фон страницы** — фиксированный, `background-attachment: fixed`, многоточечный вертикальный градиент по зонам секций.
2. **Starfield (canvas, `position: fixed`)** — 180–250 звёзд, размеры 1–3 px, три класса яркости; ~15 % звёзд мигают (opacity 0.2 ↔ 1, случайный период 2–5 с). Очень медленный параллакс: смещение = `scrollY * 0.15`.
3. **Облачные слои** — 3 pixel-art PNG во всю ширину, `background-repeat: repeat-x`, параллакс-коэффициенты 0.25 / 0.45 / 0.7. Ближний слой темнее и ниже.
4. **Контент.**
5. **CRT-оверлей (опционально, по умолчанию ВКЛ, но еле заметный):** горизонтальные сканлайны `repeating-linear-gradient(rgba(255,255,255,0.02) 0 1px, transparent 1px 3px)`, `pointer-events: none`, `position: fixed`. Плюс лёгкая виньетка по краям.

| Звёзды | Случайное мигание, медленный параллакс |
| Облака | Параллакс по скроллу + очень медленный горизонтальный дрейф (60–120 с на цикл) |
| Nav-ссылки | При hover — подчёркивание пиксельным пунктиром, цвет → акцент, **без** плавного цветового transition (`transition: none` — резкое переключение читается «пиксельнее») |
| CTA-кнопка | При hover — сдвиг вверх на 2 px + усиление обводки; при active — сдвиг вниз на 2 px (эффект нажатия физической кнопки) |
| Кубки/тиры | Пульсация свечения 3 с, у центрального амплитуда выше |
| FAQ | Раскрытие высоты 250 мс, `+` → `−` без анимации поворота |
| Карусель | Кроссфейд фона 400 мс, текст fade+slide 20 px |

**Обязательно:** `@media (prefers-reduced-motion: reduce)` отключает float, дрейф, мигание звёзд и печать (текст показывается сразу).

## 8. АДАПТИВ

**Брейкпоинты: 1440 / 1024 / 768 / 480.**

- **≤1024:** H1 → 48 px, маскот → 160 px, timeline становится скроллируемым по горизонтали (snap-scroll).
- **≤768:** navbar → бургер, открывающийся полноэкранной панелью со звёздным фоном и вертикальным списком пунктов (пиксельная иконка бургера, не Lucide). Пьедестал наград перестраивается в колонку в порядке `WHALE → HOLDER → STARTER → бонусы`. Карусель механик: заголовок и текст на всю ширину, миниатюры уходят под текст, фон-арт остаётся, вуаль плотнее (0.7).
- **≤480:** H1 → 30 px, каунтдаун в сетку 2×2, боковые паддинги 20 px, terminal-заголовки → 16 px.
- Все pixel-спрайты подаются в 2× разрешении и масштабируются вниз c `image-rendering: pixelated`.

## 10. КАЧЕСТВО И ТЕХТРЕБОВАНИЯ

- Семантика: `<header>`, `<main>`, `<section>` с `aria-labelledby`, FAQ на `<button aria-expanded>` + `<dl>`.
- Клавиатура: видимый фокус — пиксельная обводка 2 px в акцентном цвете, **не** дефолтный синий outline.
- Контраст: body-текст ≥ 4.5:1. Fade-маска в hero — только для декоративного повторяющегося текста; не прятать под ней смысл.
- LCP-изображения (маскот, первый арт карусели) — `priority`, остальное `loading="lazy"`.
- Canvas-звёзды: `requestAnimationFrame`, пауза при `document.hidden`, ререндер только мигающих звёзд.
- Никаких CLS: у всех спрайтов заданы `width`/`height`.
- Цель Lighthouse: Performance ≥ 90, Accessibility ≥ 95.
